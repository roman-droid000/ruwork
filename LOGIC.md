# Логика проекта RUWORK

RUWORK — демо-маркетплейс фриланс-услуг. Сервер на FastAPI хранит все данные в SQLite (`ruwork.db`) и проверяет все действия с деньгами и аккаунтами. Браузер (`public/index.html`) только рисует страницы и обращается к API через `fetch`. В `localStorage` сайт ничего не пишет.

## 1. Сервер (`app/main.py`)

1. При старте `init_db()` создаёт таблицы и, если каталог пуст, загружает услуги и продавцов из `app/seed.json`.
2. Маршруты `/api/...` — JSON API (документация: `/api/docs`). Неизвестный `/api/...` → `404`.
3. Любой другой путь: если такой файл есть в `public/`, он отдаётся, иначе отдаётся `index.html` (SPA-фолбэк). Выход за пределы `public/` через `../` невозможен.

## 2. Клиент: маршрутизация

При загрузке `boot()` запрашивает `/api/meta`, `/api/gigs`, `/api/state` и рисует экран. Навигация через хэш, `route()` перерисовывает `#app`:

| Хэш | Экран |
|---|---|
| `#/` | Главная: поиск с подсказками, категории, популярные услуги |
| `#/catalog` | Каталог с фильтрами |
| `#/gig/<id>` | Страница услуги: тарифы, описание, продавец, отзывы, чат |
| `#/checkout` | Корзина и оплата |
| `#/dashboard` | Аккаунт (или вход/регистрация) |

Корзина хранится в памяти страницы и пропадает при перезагрузке, как и раньше.

## 3. База данных

| Таблица | Что хранит |
|---|---|
| `users` | id, имя, email, соль, хэш пароля |
| `sessions` | токены входа (cookie `ruwork_sid`, HttpOnly, 30 дней) |
| `sellers` | описание и отзывы продавцов каталога |
| `gigs` | услуги: встроенные (`g-001…`) и объявления пользователей (`u-…`, с `owner_id`) |
| `orders` | заказы: номер, услуга, тариф, статус, сумма, способ оплаты, время |
| `wallets` | баланс монет пользователя |
| `wallet_ops` | операции: пополнение, вывод, оплата, возврат |
| `chat_messages` | история чатов (по пользователю или по гостевой cookie `ruwork_vid`) |

## 4. Услуги и тарифы

Тарифы вычисляет `mk_tiers(base)` (`app/logic.py`) из базовой цены:

| Тариф | Цена | Срок | Правки |
|---|---|---|---|
| Эконом | base × 1 | 3 дня | 1 |
| Стандарт | base × 2 | 5 дней | 3 |
| Бизнес | base × 4 | 8 дней | ∞ |

Поиск и фильтры работают в браузере по загруженному каталогу: слова без окончаний, синонимы (`SYN`), совпадение в названии весит больше, чем в подкатегории.

## 5. Аккаунты (`app/auth.py`, `app/routes/account.py`)

- Регистрация: имя ≥ 2 символов и не занято, корректный email, пароль ≥ 8 символов с буквами и цифрами, совпадение паролей, согласие с условиями.
- Email нормализуется (у Gmail убираются точки и `+метки`).
- Пароль хранится как PBKDF2-SHA256, 150 000 итераций, случайная соль. Проверка идёт на сервере.
- Смена имени обновляет продавца во всех объявлениях пользователя. Смена пароля требует текущий пароль.

## 6. Заказы (`app/routes/money.py`)

`POST /api/orders` с корзиной `{items:[{id,tier}], method}`. Цены берутся из БД, а не от клиента. Заказать собственную услугу нельзя.

- **СБП (демо):** заказ создаётся со статусом «Ожидает подтверждения».
- **Баланс:** в одной транзакции проверяется и списывается баланс, пишутся операции «Оплата заказа», заказ сразу «В работе».

```
Ожидает подтверждения ──(1 минута)──► В работе ──(24 часа)──► Выполнен
          │                               │
          └────────── Отменён ◄───────────┘
```

Статусы двигает `tick()` при каждом чтении состояния; страница аккаунта опрашивает `/api/state` раз в 5 секунд. При отмене заказа, оплаченного с баланса, монеты возвращаются (операция «Возврат»).

## 7. Кошелёк

- **Пополнение:** целое число 100–100 000 → заявка «В обработке», зачисляется кнопкой «Зачислить» (демо).
- **Вывод:** от 500 монет, не больше баланса, телефон `+7XXXXXXXXXX`, банк из списка, подтверждение паролем на сервере. Комиссия 2 %, минимум 10 монет. Монеты списываются при создании заявки, отмена их возвращает.

## 8. Свои объявления

Категория, подкатегория, название, описание, цена (≥ 100 ₽ и не ниже минимума подкатегории), до 5 тегов. Текст экранируется на сервере. Удалить можно только своё объявление.

## 9. Чат с продавцом (`app/routes/chat.py`)

- Сообщение сохраняется в БД, затем сервер формирует ответ.
- Если задан `ANTHROPIC_API_KEY`, ответ пишет Claude по данным услуги и последним 10 сообщениям (до 600 символов, без подтверждения заказов и выдуманных цен).
- Без ключа, при ошибке API или отказе модели отвечает `local_reply()` по ключевым словам: цена, сроки, правки, оплата, приветствие.

## 10. Ограничения демо

- Платежи и выводы не настоящие: зачисление и выплату подтверждает сам пользователь. Для реального запуска их должен подтверждать платёжный шлюз.
- Сессии хранятся в SQLite; для нескольких серверов понадобится общая БД (например, PostgreSQL).
