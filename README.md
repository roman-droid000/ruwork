# RUWORK

Маркетплейс фриланс-услуг: сайт-одностраничник и сервер на Python + FastAPI, данные хранятся в SQLite.

## Требования

- Python 3.10 или новее

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 4000
```

Затем откройте в браузере: <http://localhost:4000>

База `ruwork.db` создаётся при первом запуске, туда же загружается каталог услуг.

### Полезные варианты

```bash
uvicorn app.main:app --port 4000 --reload        # автоперезапуск при изменении кода
uvicorn app.main:app --host 127.0.0.1 --port 9000 # другой порт, доступ только с этого компьютера
RUWORK_DB=/path/to/other.db uvicorn app.main:app  # другой файл базы
ANTHROPIC_API_KEY=... uvicorn app.main:app        # ИИ-ответы в чате через Claude
```

Без `ANTHROPIC_API_KEY` чат отвечает заготовками по ключевым словам. Модель можно сменить переменной `RUWORK_AI_MODEL`.

Остановить сервер — `Ctrl+C`. Документация API: <http://localhost:4000/api/docs>

## Структура проекта

```
ruwork/
├── app/
│   ├── main.py          # FastAPI: подключение API, раздача public/, SPA-фолбэк
│   ├── db.py            # схема SQLite и начальное заполнение
│   ├── seed.json        # начальный каталог: категории, услуги, продавцы, описания
│   ├── auth.py          # пароли (PBKDF2), сессии в cookie
│   ├── logic.py         # тарифы, статусы заказов, комиссии, автоответы
│   └── routes/          # account, catalog, money (заказы и кошелёк), chat
├── public/
│   └── index.html       # сайт (разметка, стили и клиентская логика)
├── requirements.txt
├── LOGIC.md             # описание логики проекта
└── README.md
```

## Что есть на сайте

- Каталог услуг с категориями, фильтрами и поиском
- Карточки исполнителей с описанием, тарифами и отзывами
- Корзина, оформление заказа, оплата (демо: СБП или баланс монет)
- Личный кабинет: заказы, кошелёк, свои объявления
- Чат с ИИ-помощником продавца

> Это демо-версия: платежи не проводятся по-настоящему.
